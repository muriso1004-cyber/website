# 내가 찾던 부동산 MVP

동작구 재개발·노량진뉴타운·신속통합기획 매물을 초기투자금과 총 예상 매수가 기준으로 탐색하는 반응형 웹 프로토타입입니다.

## 실행

별도 설치가 필요하지 않습니다. 이 폴더에서 정적 서버를 실행하세요.

```powershell
python -m http.server 4173
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 주요 경로

- `#/` 홈
- `#/search` 예산 기반 매물 검색
- `#/areas` 재개발 구역별 정보
- `#/market-status` 노량진 구역별 거래가능·거래완료 현황
- `#/progress` 노량진 1~8구역 이주·철거·공사 진행상황
- `#/transactions` 노량진·상도 실거래내역
- `#/property/BLOG-224384307033` 블로그 확인매물 상세
- `#/area/noryangjin` 노량진 구역 분석
- `#/area/sangdo` 상도 신속통합기획 분석
- `#/insights` 김소장의 블로그 분석글 모음
- `#/contact` 상담 신청
- `#/landing` 네이버 파워링크용 광고 랜딩
- `#/privacy` 개인정보 처리 안내
- `#/admin` 매물 등록 및 자동계산

네이버 광고 최종 URL은 공개 도메인이 연결된 뒤 아래 형식으로 사용합니다. `utm_source=naver`가 있으면 해시 주소 없이도 광고 랜딩을 표시합니다.

```text
https://공개도메인/?utm_source=naver&utm_medium=cpc&utm_campaign=noryangjin
```

## 파워링크·모바일 운영 준비

- 모바일 하단에 `전화 상담`과 `카카오 상담`을 고정해 한 번에 연결합니다.
- 첫 화면의 `재개발 정보 검색`에서 구역·매물·실거래·분석 콘텐츠를 통합 검색합니다.
- `김소장 안내봇`은 현재 사이트가 보유한 정보로 경로를 안내하며, 입력 내용을 서버로 전송하거나 저장하지 않습니다.
- 광고 랜딩은 노량진뉴타운 매물, 초기투자금, 총 예상 매수가, 구역별 진행상황을 한 화면에 배치합니다.
- 760px 이하에서는 매물 카드를 가로로 넘기고, 입력 필드는 16px 이상으로 유지하며, 표는 화면 안에서 가로 스크롤됩니다.
- 전화·카카오 버튼은 `dataLayer`에 `consultation_click` 이벤트를 남길 준비가 되어 있습니다. 실제 전환 분석은 운영 도메인에서 사용할 네이버 전환 스크립트 또는 분석 도구를 연결한 뒤 개인정보 안내를 갱신해야 합니다.
- 상담 준비 양식은 현재 서버로 정보를 보내지 않습니다. 입력 내용을 기기에서 복사하고 카카오톡 오픈채팅을 여는 방식입니다.

파워링크 심사 전 필수 확인:

1. 광고가 연결될 공개 HTTPS 도메인을 준비하고 모바일·데스크톱에서 모든 화면이 열리는지 확인합니다.
2. 사용자가 제공한 `중개사무소 등록번호 11590-2025-00024`와 별도로, 사업자등록증상의 **사업자등록번호**를 메인 또는 푸터에 추가합니다. 현재 값이 제공되지 않아 임의로 넣지 않았습니다.
3. 상호, 대표자명, 주소, 전화번호가 사업자등록증과 동일한지 최종 확인합니다.
4. 실제 광고 문구와 랜딩 내용이 일치하도록 키워드별 최종 URL을 설정합니다.
5. 광고 성과 측정 도구를 설치하면 수집 항목, 보유기간, 위탁·제3자 제공 여부를 개인정보 처리 안내에 추가합니다.

## 데이터 동작

노량진뉴타운 매물의 기준 출처는 **내가 찾던 부동산 네이버 블로그**(`partir_12`)입니다. `assets/noryangjin-blog-properties.json`에 게시글별 매물번호, 등록일, 확인 주차, 금액 구조, 거래상태, 대표 이미지와 원문 URL을 저장합니다. 대표 이미지는 RSS 게시글의 첫 이미지를 `assets/properties/`에 내려받아 사용하므로 공개 사이트에서도 네이버 이미지 핫링크에 의존하지 않습니다.

사이트를 열면 이 JSON을 우선 불러오며, 각 화면에 `2026년 8월 3주차 확인매물` 형식의 확인 시점과 게시글 등록일을 표시합니다. 게시글에서 총매수가 등 일부 금액을 확정할 수 없는 경우 임의 계산하지 않고 **원문 확인**으로 표시합니다.

관리자에서 직접 등록하거나 상태를 변경한 데이터는 브라우저 `localStorage`에 저장되며, 공개 매물은 홈·검색·구역 화면에 즉시 반영됩니다.

블로그 URL을 함께 등록할 수 있으며 관리자에서 상태를 `거래 완료`로 변경하면 검색·추천매물에서 제외되고 거래완료 아카이브로 이동합니다.

- 블로그: `https://blog.naver.com/partir_12`
- 네이버 클립: `https://naver.me/xqbPaWUt`
- 인스타그램: `https://www.instagram.com/naega_find/`
- RSS: `https://rss.blog.naver.com/partir_12.xml`
- 현재 반영 기준일: `2026-08-20`

`scripts/sync-naver-blog.mjs`는 RSS의 최근 노량진 1~8구역 매물 게시글을 확인해 JSON의 등록일·확인 주차·대표 이미지·원문 링크·거래완료/보류 상태를 갱신합니다. 새 게시글의 금액은 자동 추정하지 않고 **비공개·광고정보 검수 대기**로 추가합니다. `.github/workflows/sync-naver-blog.yml`은 GitHub에서 6시간마다 JSON과 대표 이미지를 함께 갱신하도록 준비되어 있습니다.

구역별 사업단계는 `assets/noryangjin-progress.json`에서 관리합니다. 2026년 8월 15일 블로그 총정리를 기준으로 1·3구역은 이주, 4·5·7구역은 철거, 2·6·8구역은 공사 단계로 구분하며 기준일과 원문 링크를 화면에 함께 표시합니다.

- 초기투자금 = 매매가 - 승계가능 대출
- 일반적인 총 예상 매수가 = 매매가 + 예상 분담금
- 예상 환급금은 권리가액보다 조합원분양가가 낮아 환급이 예상되는 특수한 경우에만 차감하고 화면에 표시
- 거래 완료 매물은 기본 검색에서 제외
- 비공개 매물은 고객 화면에서 제외

## 중개대상물 표시·광고 정보

매물 상세에는 중개사무소 명칭·소재지·연락처·등록번호·개업공인중개사 성명과 함께 아래 광고정보 검수표가 표시됩니다.

- 소재지, 면적, 가격, 중개대상물 종류, 거래형태
- 건축물 해당 시 해당 층·총 층수, 사용승인·검사일, 방향과 기준, 방·욕실 수, 입주가능일, 주차대수, 관리비와 세부내역

관리자 신규 등록은 위 항목을 모두 입력하고 **광고정보 검수 완료**를 체크해야 공개 상태로 저장됩니다. 블로그에서 자동 추가된 신규 매물은 검수 전까지 비공개입니다. 기존 공개 매물은 현재 원자료에 없는 항목을 임의로 만들지 않고 `광고정보 검수 중`·`확인 필요`로 표시하므로, 운영 광고에 사용하기 전 실제 중개의뢰 내용과 건축물대장·토지대장 등 관계 장부로 보완해야 합니다.

- [공인중개사법 시행령 제17조의2](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lspttninfSeq=106742)
- [중개대상물의 표시·광고 명시사항 세부기준](https://www.law.go.kr/admRulLsInfoP.do?admRulSeq=2100000250356)

## GitHub 실거래 동기화

`#/admin`의 **GitHub 실거래 데이터 연결**에서 GitHub Actions가 갱신하는 두 Raw JSON URL을 등록합니다.

- 노량진뉴타운 JSON URL
- 상도 신속통합기획 JSON URL

지원 구조는 배열 또는 `{ "transactions": [] }`, `{ "data": [] }`입니다. 권장 필드는 다음과 같습니다.

```json
{
  "region": "노량진뉴타운",
  "area": "노량진7구역",
  "contractDate": "2026-08-20",
  "propertyType": "입주권",
  "areaSqm": 84.9,
  "floor": "-",
  "price": 2200000000,
  "source": "국토교통부 실거래가 공개시스템"
}
```

snake_case(`contract_date`, `property_type`, `area_sqm`, `deal_amount`)와 일부 한글 키도 자동 변환합니다. URL이 비어 있거나 동기화에 실패하면 화면 구조 확인용 예시 데이터가 표시됩니다.

현재는 제품 흐름 검증용 MVP이며, 운영 배포 전 Supabase 인증·DB·서버 검증과 각 매물의 광고정보 최종 검수가 필요합니다.
